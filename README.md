## ✨ Overview

ConstructFlow is a premium SaaS Construction Management Platform for **Contractors** and **Clients** to manage house construction projects end-to-end — materials, costs, labour, plans, approvals, and progress updates.

---

## 🎨 Design

- **Ultra-modern 2026 UI** — Dark + Light mode
- **Glassmorphism** — Premium glass cards with blur effects  
- **Smooth animations** — Micro-interactions on every element
- **Mobile responsive** — Collapsible sidebar, adaptive layouts
- **Chart.js** — Live pie, doughnut, bar, and line charts
- **Zero dependencies** — Pure HTML/CSS/JS, no build step needed

## 🚀 Getting Started

### Option 1 — Open directly (no server)
```
Double-click index.html in your browser
```

### Option 2 — Node.js dev server
```bash
npm start
# → http://localhost:3000
```

### Option 3 — VS Code Live Server
Right-click `index.html` → **Open with Live Server**

## 👥 User Roles

### 🏠 Client Portal
- Live construction progress tracking
- Budget transparency & payment history
- Stage-by-stage timeline with before/after photos
- One-click stage approvals
- Direct chat with contractor

### ⚙️ Contractor Portal
- Multi-project management dashboard
- Material inventory & supplier tracking
- Worker attendance, wages & team assignments
- Blueprint / CAD file uploads with version control
- Daily site reports with photo uploads
- Financial analytics, invoicing & profit analysis
- AI-powered material cost estimator
- Smart delay predictions & budget alerts
- Client communication hub
